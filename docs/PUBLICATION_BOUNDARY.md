# 🔒 Publication boundary

This public portfolio contains project descriptions, synthetic fixtures, source code, tests and technical runbooks.

Keep outside public repositories:

- draft or signed reference letters and signatory contact details;
- private CV versions, identity documents and employment records;
- recruitment correspondence, personal assessments and application drafts;
- employer source code, datasets, internal URLs and confidential measurements;
- access tokens, credentials and local machine-specific paths.

Employment titles must match confirmed records. Functional focus and target roles should be labelled separately. Independent lab technology is not automatically professional experience.

Before publishing, review the actual diff and check links, identity details, evidence scope and whether each document belongs in a public project. Ignoring a path only helps prevent accidental future additions; it does not remove content already committed.
